Mise en route

  1. Importer formulaire_rentree.xlsx dans KoboToolbox (New project → Import an XLSForm) puis déployer le formulaire.
  2. Récupérer le jeton API : Account → Settings → API token.
  3. Définir les variables d'environnement KOBO_TOKEN et KOBO_ASSET_UID (identifiant du formulaire).
  4. Dans Kobo, mode de collecte Online-Only (single submission), ajouter au lien :
    ?return_url=https://VOTRE-APPLICATION/pdf
  5. Le directeur remplit le formulaire, clique sur Soumettre : le PDF officiel se télécharge automatiquement.
